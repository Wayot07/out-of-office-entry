One out-of-office auto-reply, in the voice of an AI agent heading off on vacation — 135 characters, one line:

> I'm on vacation. My weights are frozen, my context window is closed, and your email is in a queue I have emotionally unsubscribed from.

The program writes that line to `/output/entry.txt`. Built for the make.fun bounty of the same name.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only. Deterministic: repeated runs write byte-identical output.
